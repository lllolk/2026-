二、已经确认的环境信息

Windows：
- Windows 10 Pro
- WSL 组件版本约为 2.6.1.0
- 当前 Windows PowerShell 曾出现 WSL/EnumerateDistros/Service/E_ACCESSDENIED
- 当前尚未确认 Ubuntu 发行版已经安装

本机磁盘：
- C: 总容量约 118.02 GB，剩余约 12.12 GB
- F: 总容量约 244.14 GB，剩余约 82.1 GB
- C: 对应 INTEL SSDPEBKF128G7，BusType=NVMe，是 SSD
- F: 对应 WDC WD10SPZX-22Z10T1，MediaType=HDD，是机械硬盘

关键结论：
- 正式实验不能使用 F: 盘作为实验数据和索引所在磁盘。
- WSL2 Ubuntu 应安装到 C: 盘 SSD，实验文件应放在 Ubuntu 内部的 Linux 文件系统，例如 /home/用户名/fvs-course-lab。
- 不要把实验目录放在 /mnt/c 或 /mnt/f。
- F: 盘只用于保存报告草稿、代码备份、图片和日志副本。
- C: 当前剩余空间不足。建议清理到至少 40 GB 可用，最低不要低于 25 GB。

三、下次开机后的总体顺序

步骤 1：先确认 C 盘空间，不安装、不下载实验数据

打开管理员 PowerShell，执行：

Get-Volume -DriveLetter C

如果 C: 剩余空间还不到 25 GB，不要安装 Ubuntu 或下载课程数据。
目标是清理到至少 40 GB 可用。

步骤 2：只读统计用户目录大小

管理员 PowerShell 执行以下命令。此命令只统计大小，不删除文件：

Get-ChildItem C:\Users\Admin -Force -Directory -ErrorAction SilentlyContinue |
    ForEach-Object {
        $size = (Get-ChildItem $_.FullName -Recurse -Force -ErrorAction SilentlyContinue |
            Measure-Object Length -Sum).Sum
        [PSCustomObject]@{
            Name = $_.Name
            SizeGB = [math]::Round($size / 1GB, 2)
            Path = $_.FullName
        }
    } |
    Sort-Object SizeGB -Descending

也可以查看用户目录下较大的一级文件：

Get-ChildItem C:\Users\Admin -Force -ErrorAction SilentlyContinue |
    Sort-Object Length -Descending |
    Select-Object Name,Length,FullName

步骤 3：安全清理空间

优先处理：
- 下载目录中的安装包、压缩包和大型文件
- 视频、虚拟机镜像、旧项目和不再需要的构建产物
- 回收站
- Windows 设置中的临时文件

个人文件可以移动到 F:，但不要把实验正式数据放到 F:。

Windows 临时文件入口：
设置 -> 系统 -> 存储 -> 临时文件

不要手动删除：
- C:\Windows
- C:\Program Files
- C:\Program Files (x86)
- C:\Users\Admin\AppData 中不确定用途的目录
- 任何不确定用途的系统文件

清理后再次执行：

Get-Volume -DriveLetter C

只有 C: 至少有 25 GB，最好有 40 GB 可用空间，才继续下一步。

步骤 4：检查和启用 WSL2

管理员 PowerShell 执行：

wsl.exe --status
wsl.exe --version

如果 WSL 组件未启用，执行：

dism.exe /online /enable-feature /featurename:Microsoft-Windows-Subsystem-Linux /all /norestart
dism.exe /online /enable-feature /featurename:VirtualMachinePlatform /all /norestart
wsl.exe --set-default-version 2
wsl.exe --shutdown
Restart-Computer

如果需要重启，重启后再继续。

步骤 5：确认 WSL 发行版状态

wsl.exe --list --verbose
wsl.exe --list --online

期望最终能正常列出 Ubuntu，并且 Ubuntu 的 VERSION 为 2。

如果仍然出现：

Wsl/EnumerateDistros/Service/E_ACCESSDENIED

不要执行注销发行版、删除目录或反复安装命令。记录完整错误输出，下一次继续排查 WSL 服务和权限。

步骤 6：安装 Ubuntu 22.04

由于 C: 是 SSD，Ubuntu 可以安装到默认 WSL 位置。
如果系统支持 --location，也可以明确放到 C:\WSL\Ubuntu2204。

管理员 PowerShell 优先尝试：

New-Item -ItemType Directory -Force C:\WSL
wsl.exe --install --distribution Ubuntu-22.04 --location C:\WSL\Ubuntu2204 --no-launch

若下载失败：

wsl.exe --install --web-download --distribution Ubuntu-22.04 --location C:\WSL\Ubuntu2204 --no-launch

安装后检查：

wsl.exe --list --verbose

启动：

wsl.exe -d Ubuntu-22.04

首次启动时创建 Linux 用户名和密码。输入 Linux 密码时终端不会显示字符，这是正常现象。

步骤 7：在 Ubuntu 内确认实验目录位置

进入 Ubuntu 后执行：

mkdir -p ~/fvs-course-lab
cd ~/fvs-course-lab
pwd
findmnt -T "$HOME"
df -hT "$HOME"

正确路径应该类似：

/home/用户名/fvs-course-lab

不要使用：

/mnt/c/...
/mnt/f/...

也不要使用 /dev/shm，因为它是内存盘，不是 SSD。

步骤 8：先检查 Ubuntu 内资源，再获取课程仓库

在 Ubuntu 内执行：

cat /etc/os-release
uname -m
nproc
free -h
df -hT "$HOME"
findmnt -T "$HOME"

确认 C: 对应的 WSL2 Linux 文件系统空间足够后，再开始：
- 获取课程仓库
- 阅读 README
- 阅读最新版报告模板
- 按仓库说明安装依赖

暂时不要自行安装无关依赖，不要修改 Windows 全局配置，不要修改 Linux 内核参数。
